# v0.2.21

## Communities in search

There is a new **Communities** tab. It indexes NIP-72 community definitions
(kind 34550) from your configured relays and shows each community's name,
description and image.

A community is addressed by a relay coordinate rather than a web page, so its
row has no external link. The tab is there so communities are discoverable
alongside everything else instead of only inside a client.

## Apps in search

There is a new **Apps** tab for Zapstore/NIP-82 software listings (kind 32267).
Each result shows the app's icon, name, summary and supported platforms
(Android, Linux, Web, and so on).

Clicking an app opens its store listing at
`https://zapstore.dev/apps/<app-id>`. On Android, Zapstore registers that https
path as a verified App Link, so the same click opens the installed Zapstore app
when it is present, and the web listing everywhere else.

App listings are normally only carried by a store's catalog relay, so the
crawler adds `relay.zapstore.dev` for the app subscription only. Change it with
**`SEARCH_APP_RELAYS`** in `.env`, or turn the adapter off with
`NCC_SEARCH_ENABLE_APPS=false` on `search-crawler`. Communities can be turned
off with `NCC_SEARCH_ENABLE_COMMUNITIES=false`.

Both features are in the shared UI, so they apply to the server-hosted search
page and to the nsite edition. The nsite edition's default relay list now
includes `relay.zapstore.dev` as well; remove it in the local index settings to
opt out.

## Upgrading

Normal upgrade, no manual steps:

```sh
cd /opt/ncc-server
sudo make bundle-upgrade REF=v0.2.21
```

or use **Upgrade to v0.2.21** on the admin panel's Overview page. If you pin
images yourself, `SEARCH_IMAGE` and `SEARCH_UI_IMAGE` must move to `:0.2.21`.

The search index gains a `platforms` column. The crawler migrates the existing
SQLite file automatically on first start; the API waits and retries until that
has happened, so there is nothing to run by hand.

## Verifying

1. Search for a community name; the **Communities** tab should show its image
   and description.
2. Open the **Apps** tab and click an app. On a phone with Zapstore installed
   it should open in the store app; otherwise it should open the web listing.
3. Old results are unaffected: the new kinds only add rows.
