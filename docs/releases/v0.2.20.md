# v0.2.20

## Blur NSFW media in search

Both editions of the search UI now have a **Blur NSFW media** switch under
**Settings → Search preferences**, on by default:

- Images, videos and shorts whose publisher tagged them NSFW or otherwise
  sensitive are shown blurred behind a "click to show" overlay.
- Revealing one tile only reveals that tile; the full-size preview has its
  own "Show anyway" step.
- A blurred video is never started, so audio cannot play from media you have
  not revealed yet.
- The switch is independent of safe search: it is the layer that matters when
  safe search is **off** and flagged results are shown instead of hidden.

The app still makes no safety judgment of its own — it only respects the
publisher's own NIP-68/71 `content-warning` label. Unrelated warnings such as
"flashing lights" are left alone.

This is in the shared UI, so it applies to the server-hosted search page
(`ncc://<npub>/search/`) and to the nsite build alike.

## Safer upgrade button

The admin panel now only offers an upgrade once every component image for that
release is published to the registry, and the upgrade runner verifies the
pinned images exist before changing the host. A release whose images are
still building is no longer offered.

## Upgrading

Normal upgrade, no manual steps:

```sh
cd /opt/ncc-server
sudo make bundle-upgrade REF=v0.2.20
```

or use **Upgrade to v0.2.20** on the admin panel's Overview page. If you pin
images yourself, `SEARCH_UI_IMAGE` must move to `:0.2.20` to get the new UI.

## Verifying the blur

1. Turn **Safe search** off in Settings, if it is on.
2. Search for an author/page with publisher-flagged media, or open the
   **Images**, **Videos** or **Shorts** tab.
3. Flagged tiles appear blurred; clicking one reveals only that tile, and its
   preview asks again before playing or showing the full file.
